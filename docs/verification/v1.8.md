# v1.8 代理出口地区验证

分支：`feat/v1.8-proxy-region`，基于v1.7。Android业务代码未修改。固定提交研究与许可证边界见 [Muse会话研究](../muse-session-research.md)；被核验仓库没有可直接照搬的“出口IP→语言/时区”实现，本项目独立实现，未复制其未明确许可的实质代码。

## 功能

- 指纹新增语言/时区来源：proxy/manual/native。旧账号已有非空值映射为manual；新空值默认proxy。保存空值字段时同步推断来源；显式模式优先。
- 定位查询只经账号代理到固定 `https://ipwho.is/`，携带Accept与identity编码，不带Cookie/管理token，不跟随重定向；验证HTTP状态、内容类型、未压缩32KiB上限、IP、ISO国家码和IANA时区。失败消息固定，不回显供应商正文或代理凭据。
- 国家默认语言为受控映射启发式；未映射国家要求手动语言。IP不证明真实母语，时区使用供应商返回的IANA值。
- 每账号独立缓存，绑定完整代理字符串（含凭据）SHA256；完整代理变更失效。最多2并发、64等待，成功TTL1小时、失败冷却60秒，强制刷新不绕过失败冷却。同账号去重，取消迟到结果不写回。运行中文档允许使用同代理过期缓存，新打开账号时重新确认。
- 缓存文件 `regions.json` 使用0700目录/0600文件，只保存账户ID、代理哈希、出口IP、国家、语言、时区和检测时间；不保存代理URL/密码或原始错误。坏行、未来/过期时间、任意locale、无效IP/时区均拒绝。
- 打开账号页面之前等待自动地区确认；自动值不可用时返回503，不使用访问设备或服务器位置。HTTP、WS、Worker和自检使用同一生效账号配置。手动值、Cookie和固定种子不变。
- 代理测活成功、故障切换、地区手动刷新后读取状态；已在运行页面显示重新打开按钮。

## 使用边界

定位服务是外部供应商，项目不依赖其可用性承诺；关闭指纹或不需地区同步时可保持原生。语言为国家默认值而非账号使用者身份判定。实际Muse账号登录后的站点风控没有自动验证，也不宣称永久登录或出口变更完全不可检测。

WebSocket升级响应头不被底层传输暴露，因此该路径不同步101 Set-Cookie；HTTP响应和会话维护继续轮换Cookie。该限制已在v1.7记录。
