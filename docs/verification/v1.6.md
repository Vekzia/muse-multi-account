# v1.6 每账号指纹验证记录

分支 `feat/v1.6-account-fingerprints`，基于 Linux WebUI v1.5。Android app 源码未修改。

## 功能

- 账号固定32位种子；旧账号读取迁移保持关闭和确定性种子，新账号创建仅随机一次。显式重新生成才更换种子。
- Windows/macOS/Android Chrome131预设，自定义UA、平台、语言、IANA时区、屏幕/DPR元数据、CPU/内存字段、WebGL厂商/渲染器标签。
- Canvas固定噪声、可选Audio读出噪声、WebRTC构造器阻断、webdriver字段覆写。
- HTTP和WebSocket使用同一UA/语言配置；自定义UA时移除冲突Client Hints。页面脚本在已有请求桥和上游脚本之前执行。
- WebUI独立指纹草稿、If-Match冲突检查、保存/生成/恢复原生及同账号Origin自检。配置存储和备份包含种子。

## 审查修复

- 编码API前缀导致raw URL守卫绕过：鉴权及严格校验使用Fastify已匹配路由，新增未认证编码生成/session路径401和非法fp参数400回归。
- 旧版本接受的休眠fp文本导致升级整体读失败：仅旧字段形状走迁移并保持关闭；新配置仍严格校验。
- P3画布导出色彩变化：仅sRGB RGBA8二维不透明像素扰动，P3/HDR/float16及非二维输出保留原生。
- 超限/不支持编码HTML默默跳过指纹：开启时返回502中文未应用提示、no-store，防止页面身份与请求头不一致；条件请求验证器被移除以避免旧文档304复用。
- 服务重启测试的旧HTTP连接池复用：测试客户端明确使用Connection:close，不通过重试掩盖服务错误。

## 覆盖限制

这是页面脚本和服务端请求头配置，不是改造Chromium内核。TLS/HTTP2、真实字体与GPU能力、WebGPU、Worker/未注入frame、OffscreenCanvas和部分Date/数字locale方法保持原生。screen只是元数据，不改变窗口布局尺寸。脚本可被检测或绕过，未声称通过站点风控。

Canvas仅sRGB/RGBA8二维opaque RGB±1。Audio getChannelData返回副本，需copyToChannel写入；可能改变依赖可写视图的音频编辑逻辑。WebRTC阻断可能影响音视频通话。预设标明固定Chrome131版本。

真实 Muse 匿名登录页已使用 Windows 预设+zh-CN+Asia/Shanghai+Canvas 噪声检查：输入框显示「手机号或邮箱」，页面 navigator.userAgent 为 Windows Chrome131、language=zh-CN、Intl.timeZone=Asia/Shanghai、getTimezoneOffset=-480。页面及资源返回200/206；保留v1.5已观察到的React hydration #418警告并恢复客户端渲染。未登录真实账号，未验证真实登录后的任务全流程。CI结果在发布后单独核验。
