## 使用边界

- 默认管理监听 127.0.0.1:8787，账号 Origin 使用固定端口 8788–8819。公开监听需要设置 token/publicHost，并开放相应账号端口。
- 默认覆盖账号 ID 1–32，删除 ID 不回收；可通过端口范围配置扩展至1024。端口 Origin 不复用给另一个账号。
- 固定上游为 Muse 主站与显式 API aliases；请求不能指定任意目标 URL。HTTP(S)/SOCKS5代理和 CookieJar均绑定账号。
- 请求桥只把固定 Muse URL/fetch/XHR/WS/EventSource 映射回账号 gateway；不提供完整 GPU/字体/Canvas 等指纹隔离。
- server JSON 备份包含代理凭据和完整CookieJar，与Android MUSEBAK1加密格式不同，本版未提供服务端密码加密备份。
- Compose提供HTTP本机/信任局域网入口；公网需要给管理和所有账号Origin一致配置HTTPS，当前配置不会自动签发证书。
