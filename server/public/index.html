高级设置 · 传输、执行环境与硬件

控制服务器向 Muse 发出的 TLS 连接，不改变本机浏览器。浏览器预设会匹配所选 Chrome 版本；系统或自定义 UA 保持原值，请自行保持一致。

为受支持的 Worker 执行上下文应用账号指纹；不等同于修改整个浏览器。

标准化页面字体呈现，不移除操作系统字体；实际字形受字体覆盖范围影响。

停用 WebGPU 访问，不伪造 GPU 硬件或性能；依赖它的页面功能可能受影响。

屏幕尺寸仅覆写 screen 元数据，不调整窗口或页面视口。数字 0、文本留空表示原生。

阻止 WebRTC 会停用相关通话。Canvas 仅扰动 sRGB RGBA8 二维画布，P3/HDR 保持原生；Audio 读取返回副本，可能影响音频编辑。UA Client Hints 不伪造；Date 本地 get/set/toString 保持原生，Intl 与 toLocale 日期格式使用配置时区。

保存、重启和备份恢复保持种子；重新生成会更换种子与预设参数。

选择预设仅切换 UA；重新生成会替换草稿、填充屏幕、平台与 GPU 并立即保存，保留 Cookie、已保存的语言时区和高级策略。自检使用已保存配置；保存后已打开页面会重新打开。
